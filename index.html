03 — About

A student who builds systems

Shashank Kumar Singh is a software engineering student and builder. The work here is about making structure hold under load — in code, in data, and in the interfaces people actually use.

Interests sit across software engineering, quantitative systems, AI/ML, backend engineering, full-stack products, algorithmic trading, and data-intensive systems. The common thread is not a stack. It is the habit of decomposing a problem until the moving parts are explicit, then assembling something that can be tested.

This site is a notebook of that practice: research platforms, matching logic, social products, security analysis, and one-day prototype work — presented as they are, without a performance overlay.

01 / QuantLab

Quantitative Research Platform

QuantLab

Problem
Systematic trading research needs one path from market data through features, strategies, backtests, portfolios, and risk — not a pile of disconnected notebooks.
Approach
Build a research platform that makes each stage explicit: ingest and clean data, generate features, research strategies, run event-driven backtests, then size and stress the book.
Architecture
Market data → Clean → Features → Strategy → Backtest → Portfolio → Risk
Technology
Python · Quantitative Research · Algorithmic Trading · Market Data · Event-Driven Backtesting · Portfolio Construction · Risk Analytics · Machine Learning · FastAPI · DuckDB · SQLite · Parquet · MLflow · Optuna
Validation
Public research interface. Schematic diagrams only — no live performance claims.
Repository
GitHub · Live

02 / Mercury

Matching Engine

Mercury

Problem
Exchange behaviour is easy to wave at and hard to specify. Mercury models the load-bearing rules of an order book in Modern C++20.
Approach
A simplified electronic exchange: integer tick arithmetic, limit and market orders, partial and full fills, cancellation, modification, and scripted replay.
Architecture
CLI → Exchange → Matching engine → Order book
Technology
C++20 · CMake · GoogleTest · Google Benchmark
Validation
91 GoogleTest cases. Interactive REPL and scripted replay.
Repository
GitHub · Live

04 / PhishEye

Phishing-Domain Detection

PhishEye

Team project. Represented at Lenovo LEAP Hackathon 2026.

Problem
A suspicious URL is not one signal. PhishEye stacks complementary checks so a domain can be inspected as structure, infrastructure, content, and a model score.
Approach
Parse the URL, inspect the domain, query DNS and TLS, read content, then classify and score risk. No accuracy percentage is claimed here.
Architecture
URL → Domain → DNS → SSL → Content → ML → Risk
Technology
React · TypeScript · Vite · Python · FastAPI · PostgreSQL · Scikit-learn · DNS analysis · URL feature extraction · Threat intelligence · Machine Learning · Chrome extension · REST API · Authentication · Security validation
Validation
Team build, presented at Lenovo LEAP Hackathon 2026. Schematic scoring only.
Repository
GitHub

05 / FundMatch

Startup Scheme Discovery

FundMatch

Hack-E-Awadh 2026, Lucknow. Built and presented within one day at the venue.

Problem
Early-stage founders have to hunt government schemes by hand. FundMatch takes a startup profile and returns eligibility, matches, and an application roadmap.
Approach
Collect startup input, check eligibility, match schemes, and generate the next steps. Built as a one-day full-stack prototype.
Architecture
Startup → Eligibility → Scheme match → Roadmap
Technology
Full-stack web · AI-assisted reasoning · Eligibility analysis · Rapid prototyping
Validation
Hack-E-Awadh 2026, Lucknow. Built and presented in one day. No usage metrics.

08 — How I build

How I build

The same sequence, every time: constraints first, interface last.

  1. 01

    Understand

    Break the problem into constraints.

  2. 02

    Model

    Design the system before the interface.

  3. 03

    Build

    Implement the smallest useful architecture.

  4. 04

    Measure

    Test behaviour and performance.

  5. 05

    Refine

    Remove unnecessary complexity.

  6. 06

    Ship

    Deploy something people can actually use.
